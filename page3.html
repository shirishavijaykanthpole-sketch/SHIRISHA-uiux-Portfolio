Project 02 // Core Case Study

FYJC Portal System

Public Infrastructure HCI Research Design Systems

Re-engineering the First Year Junior College (FYJC) online admission system into a high-legibility, friction-free digital public experience for lakhs of students across Maharashtra.

01 // Context

The Problem

Legacy civic administrative infrastructure treats portal interfaces as simple raw database outputs. Dense, unformatted form fields, complex statutory quota verification paths, and obscured status markers consistently lead to high user rejection percentages.

Lakhs of young applicants and parents are left vulnerable to critical processing mistakes during stressful high-stakes secondary admission selection intervals due to absolute design logic failures.

02 // Constraints

The Challenges

The overarching engineering challenge lies in operational scalability. The interface parameters had to scale faultlessly to run under low-bandwidth networks, processing high transactions smoothly on compromised viewports while observing rigorous governmental legal confirmation tracks.

03 // Evolution

The Next Better Step

This ecosystem defines the upcoming paradigm for Maharashtra's digitized public education infrastructure. By deploying absolute progressive disclosure methodologies, separating structural steps, and implementing adaptive typographic token systems, we establish immediate clarity for citizens.

04 // Framework

Process & Success

Phase A // HCI Auditing

Extracted core procedural steps through continuous interaction modeling, identifying exactly where system drop-offs took place due to phrasing noise.

Phase B // Variable Tokens

Formulated layout guidelines using strict typographic baseline logic ensuring immediate cross-device application processing security.
